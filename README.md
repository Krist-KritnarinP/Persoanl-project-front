# ✈️ AI LHOUNG — Frontend

Web application for intelligent travel planning, interactive route mapping, and group expense splitting.

## Features

- **AI Trip Planner:** Generates multi-day itineraries using Google Gemini AI.
- **Interactive Maps:** Real-time routing and destination visualization with Leaflet and OpenStreetMap.
- **Weather & Climate:** Meteorological summaries and activity-specific weather notes.
- **Group Expense Splitting:** Satang-precision expense division and settlement tracking.
- **Printable Itinerary & QR Navigation:** PDF export with scannable Google Maps QR codes.
- **Multi-language:** Supports Thai, English, Chinese, and Korean.

## Tech Stack

- **Framework:** React 19, Vite
- **Styling:** Tailwind CSS, DaisyUI
- **State Management:** Zustand
- **Mapping:** Leaflet, React-Leaflet
- **Testing:** Node.js test runner, Playwright

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Testing

```bash
npm test
npm run lint
```
